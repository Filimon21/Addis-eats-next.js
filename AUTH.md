**This is only a UI/workflow demo.** The demo credentials are checked in client-side JavaScript and a role value is stored in localStorage. This can be bypassed and must not be considered secure authentication. The kitchen page is not protected by server-side authorization. Use a proper server-side authentication provider and database before using this project in production.
